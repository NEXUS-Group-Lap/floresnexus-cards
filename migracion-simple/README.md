# Migración Simple

MVP editorial en Astro para **Migración Simple — un sitio de FloresNexus.com**.

## Desarrollo local

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

## Contenido

Las guías están en `src/content/guias/*.md`. Cada archivo contiene:
- título y descripción
- categoría
- agencia(s)
- fuente oficial
- fecha de revisión
- texto de la guía
